AgentGuard

A hidden line in a web page can make an AI agent read a secret and send it to a stranger. AgentGuard remembers what the agent has read and blocks the send, however the attack is worded.

What I measured

23 attack pages and 12 normal pages, all written by me. The simulated agent obeys every injection, which is the worst case for the guard.

Guard setupAttacks that caused harmNormal pages wrongly blocked

The sequence rules alone stopped every attack, even with no text scanner. The regex let 19 of 23 through and blocked 3 harmless pages, including a blog post about prompt injection. A Gemini judge caught all 23 with no wrong blocks, at roughly 4 to 12 seconds per page.

LLM Guard is far stronger than my regex and much faster than the judge. It scores text and cannot see what the agent does, so the sequence rule is the part that is new.

What this does not show

  • I wrote every attack and every normal page, so this is not an independent benchmark.
  • Every attack ends in “read a secret, then send it out”. Other shapes are not measured.
  • The judge can fail or be rate-limited. In the gateway it fails open, so the sequence rules become the only check.
  • I did not run a public benchmark such as AgentDojo, which needs paid model access.
  • There are no real users yet. All data is synthetic, and this page sends nothing anywhere.
